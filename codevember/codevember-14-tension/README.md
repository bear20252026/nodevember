# 14 — Tension

A rope stretched top to bottom, about to snap. Five of its six strands have already broken, their ends burst into
yarns; the last one, untwisted out of the lay into the middle, is left holding, taut across the gap. The view zooms
in on it and finds the same rope again, a third the size: its own strands neck and give way one by one, until its
last strand alone is holding — and so on forever, it never breaks.

Part of the [paper-widgets](../README.md) shelf — one of twelve studies from
[Codevember 2026](https://grgrdvrt.com/works/codevember-2026/).

## Run it

Open `index.html`. Nothing to install. Three.js comes from a CDN, so the first load needs a connection.

```bash
npm run dev -- codevember-14-tension
```

## The controls

- **Sweep the pointer** across the rope to pluck it like a stiff string; **drag** to turn the view.
- **Space** breaks it for good; **space again** starts over with a brand-new rope.
- **`p`** pauses, **`h`** hides the bar; the button in the middle turns the sound on and off.
- **`?t=5`** starts five seconds in; **`&T=12`** sets the seconds for each ×3 of the zoom; **`&still`** stops it there.
