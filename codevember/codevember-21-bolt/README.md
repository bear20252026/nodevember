# 21 — Bolt

A diorama of a thunderstorm: on a block of meadow, its soil layers showing over a wooden base, a bolt of lightning
strikes, held at the very instant it touches the ground. It stands on one endless board of dark wood, lit only in a
pool round it. Only the bolt is still — the storm clouds over it roll on, and the rain keeps falling.

Part of the [paper-widgets](../README.md) shelf — one of twelve studies from
[Codevember 2026](https://grgrdvrt.com/works/codevember-2026/).

## Run it

Open `index.html`. Nothing to install. Three.js comes from a CDN, so the first load needs a connection.

```bash
npm run dev -- codevember-21-bolt
```

## The controls

- **Drag** to orbit, **scroll** to zoom; **space** or a click lets the bolt go — it flashes, thunder claps, stones
  fly out, and quietly a new one arrives elsewhere in the cloud.
- **`n`** a new strike, **`r`** turn round by itself, **`p`** pause the storm, **`s`** sound on/off, **`h`** hide the bar.
- **`?seed=n`** fixes the block and the bolt; **`&still`** stops the clouds and rain; **`&mute`** starts silent.
