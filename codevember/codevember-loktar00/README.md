# Codevember — loktar00

One self-contained piece per prompt word, each a single HTML file, built with three.js. One has landed so far:

**Moss — Stepping Stones**: a fox hopping forever across five floating, moss-covered rock islands at golden hour —
cushion moss and backlit grass, soft contact shadows, a filmic grade, and synthesized ambient sound (click for
sound, `M` to mute).

Part of the [paper-widgets](../README.md) shelf, kept as published from
[loktar00/codevember](https://github.com/loktar00/codevember). The repository carries no licence, so no rights are
granted beyond reading and learning.

## Run it

Open `moss/index.html`, or serve the folder. three r186 comes from a CDN; the scene, its shaders and its sound are
all in that one file.
