# Tangle

One growth, seen three ways at once: the same views side by side, one camera they share — the branch structure, its
skin and its light, each built from the same generation. All three grow at the same pace and finish together.

Part of the [paper-widgets](../README.md) shelf — one of twelve studies from
[Codevember 2026](https://grgrdvrt.com/works/codevember-2026/).

## Run it

Open `index.html`. Nothing to install. Three.js comes from a CDN, so the first load needs a connection.

```bash
npm run dev -- codevember-04-tangle
```

## The controls

- **Drag** the views to orbit; the same seed is carried in the address, so a view can be saved as a link.
- **`?seed=n`** gives one generation instead of a random one.
