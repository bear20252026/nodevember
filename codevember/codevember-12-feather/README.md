# Feather

A small creature under a coat of feathers, simulated one by one. It is a mass on springs: pick it up, shake it,
throw it, and it lands on its legs, leans with its acceleration and turns to look at the pointer. Left alone it
fluffs and shakes its coat; without feathers it shivers.

Part of the [paper-widgets](../README.md) shelf — one of twelve studies from
[Codevember 2026](https://grgrdvrt.com/works/codevember-2026/).

## Run it

Open `index.html`. Nothing to install. Three.js comes from a CDN, so the first load needs a connection.

```bash
npm run dev -- codevember-12-feather
```

## The controls

- **Pick it up and shake it** with the pointer; let go to throw it.
- **`?lab`** opens the feather lab: a bench of single feathers to work on their look.
