# Orrery

A brass orrery in the hall of an observatory, at night, as an engraved plate in a Voyages Extraordinaires: a machine
whose sun is a lamp, gears turning in its cage, the planets going round on their arms and casting shadows.

Part of the [paper-widgets](../README.md) shelf — one of twelve studies from
[Codevember 2026](https://grgrdvrt.com/works/codevember-2026/).

## Run it

Open `index.html`. Nothing to install. Three.js comes from a CDN, so the first load needs a connection.

```bash
npm run dev -- codevember-06-orrery
```

## The controls

- **Tilt (T)** tips the plate to look into the machine; **Drift (D)** lets the view drift.
- Switch between **Ptolemy** and **Copernicus**; step **back**, **pause** or go **forward** through the year.
- **Drag** the plate to orbit; the mouse wheel zooms.
