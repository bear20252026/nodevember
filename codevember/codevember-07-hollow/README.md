# Hollow

A hollow sphere of marble, a thin shell, split along seams where a noise crosses a threshold, each part framed in
brass. It starts thrown apart and rebuilds itself; the parts hovered fly off for good, and when three are left they
all lift off and the next shape comes.

Part of the [paper-widgets](../README.md) shelf — one of twelve studies from
[Codevember 2026](https://grgrdvrt.com/works/codevember-2026/).

## Run it

Open `index.html`. Nothing to install. Three.js comes from a CDN, so the first load needs a connection.

```bash
npm run dev -- codevember-07-hollow
```

## The controls

- **Drag** to orbit. **Hover** a part and it flies off for good.
- The captions under the picture switch shape; the shapes come round again.
