# Moss

A cushion of moss on a boulder, and two little ones beside it. The soil first, bare; the short leafy shoots spread
over it from a few spots until it is all green; then the long filaments rise, their capsules swell and ripen to orange.

Part of the [paper-widgets](../README.md) shelf — one of twelve studies from
[Codevember 2026](https://grgrdvrt.com/works/codevember-2026/).

## Run it

Open `index.html`. Nothing to install. Three.js comes from a CDN, so the first load needs a connection.

```bash
npm run dev -- codevember-05-moss
```

## The controls

- **Drag** to orbit; **scroll** to zoom.
- The bar has pause (`p`), grow again (`g`), a new patch (`n`), depth of field (`d`), post (`e`), and a slider for
  the growth.
