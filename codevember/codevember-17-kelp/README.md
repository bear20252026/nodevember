# Kelp

A sea floor to draw kelp on. Each plant is a stipe (the stroke drawn) and the strands hung on it — blades, fingers,
holdfast roots — a chain of joints that buoyancy lifts and the current drags, so the waves run up the stipe and whip
out along the blades. Moving the pointer stirs the water.

Part of the [paper-widgets](../README.md) shelf — one of twelve studies from
[Codevember 2026](https://grgrdvrt.com/works/codevember-2026/).

## Run it

Open `index.html`. Nothing to install. Three.js comes from a CDN, so the first load needs a connection.

```bash
npm run dev -- codevember-17-kelp
```

## The controls

- **Draw** with the pointer; the wells down the left side pick the kind of kelp.
- **Undo / redo / clear** past the wells; **⌘/ctrl z**, **⇧⌘/ctrl z** (or **ctrl y**), **space** pause, **h** hides
  the selector.
- **`?lab`** opens the kelp lab: the kinds side by side, each named.
