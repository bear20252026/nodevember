# Caustics

Caustics as the path of light, in a diorama: a long, shallow glass tank on a thick wooden shelf in a sunlit room, a
block of sand with water over it. Grains of light fall from high up in one direction, each a tiny dot with a thin
trail, and the waves bend them.

Part of the [paper-widgets](../README.md) shelf — one of twelve studies from
[Codevember 2026](https://grgrdvrt.com/works/codevember-2026/).

## Run it

Open `index.html`. Nothing to install. Three.js comes from a CDN, so the first load needs a connection.

```bash
npm run dev -- codevember-10-caustics
```

## The controls

- **Drag** to orbit, **scroll** to zoom.
- **space** pauses; **clear the sand** empties the tank; **n** turns the room to night.
